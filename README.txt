TOBC Website
=============

Files:
- index.html  — main landing page
- work.html   — dedicated Work page with 5 category sections
- style.css   — shared styling
- script.js   — shared interactions
- tobc-logo.png — supplied TOBC logo

Work navigation:
- Each Work card on index.html links to work.html#jewellery, #ethnic, #hospitality, #fashion or #product.
- "View Full Work" opens work.html.
- The Work page automatically scrolls to the requested category when a hash is present.

Google Drive:
Replace the YOUR_*_ID placeholders with the relevant Google Drive file IDs.
The existing five work IDs from the supplied HTML are retained:
YOUR_WORK_ID_1 through YOUR_WORK_ID_5.
