WORK PAGE GALLERY
-----------------
Each of the five Work categories now has a 6-image editorial gallery:
1. Jewellery
2. Ethnic Wear
3. Hospitality
4. Fashion
5. Product

The first image is larger and the other five images remain visible around it.
Clicking any supplied image opens a full-screen lightbox with:
- previous/next controls
- image counter
- keyboard arrows on desktop
- swipe navigation on mobile
- close button

This approach avoids hiding the portfolio behind an autoplay carousel while
still giving users a carousel-like full-screen browsing experience.

GOOGLE DRIVE
------------
Each category uses one existing YOUR_WORK_ID_* image plus five additional
placeholders. Replace:
- YOUR_JEWELLERY_ID_2 through _6
- YOUR_ETHNIC_ID_2 through _6
- YOUR_HOSPITALITY_ID_2 through _6
- YOUR_FASHION_ID_2 through _6
- YOUR_PRODUCT_ID_2 through _6

with the corresponding Google Drive file IDs.

The page will show a clean "ADD IMAGE" tile until each placeholder is replaced,
rather than a broken-image icon.
